A bridge, without the distance

Three steps. All local.

Your host computer keeps the room open and stores shared files.

1

Get on the same network

Connect your devices to the same Wi-Fi or Ethernet network. Keep the host running and awake.

2

Open the room

Open the host’s local IP address in your browser. Enter the room code from the host terminal.

3

Send, then download

Choose your files. When an upload finishes, open Room files on the receiving device and download it.

A few things to know

Large files: keep your browser open while uploading. You can pause and resume. After a reload, select the same file to continue a saved upload.

Fast transfers: use Ethernet for the host or a strong 5/6 GHz Wi-Fi connection. The host stores a full copy before another device can download it.

Trusted networks: the default local connection uses HTTP. The room code controls access but does not encrypt traffic. Everyone in the room can download or remove shared files.

Can’t connect? Check the host firewall and disable guest Wi-Fi client isolation. A phone’s mobile data connection cannot reach your private LAN address.
